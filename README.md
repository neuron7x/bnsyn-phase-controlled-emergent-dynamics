# BN-Syn
**BN-Syn is a wind tunnel for emergence in AI.**

It is a controlled, fail-closed laboratory for studying how capabilities arise in neural systems **before** they become opaque, distributed, and difficult to verify inside production-scale models.

Instead of asking only what is happening inside an already-trained black box, BN-Syn asks a more fundamental question:

> **Can we identify the causal precursors of capability emergence before they disappear into opacity?**

BN-Syn is built around three components:

- **AdEx + STDP** — a controlled neural substrate in which emergence can be induced, observed, repeated, and perturbed
- **Kriterion / fail-closed validation** — a formal boundary that rejects claims not supported by reproducible evidence
- **Canonical proof bundle** — machine-checkable artifacts that record each emergence-relevant run

## Core thesis
**Goal:** find universal causal invariants of emergence
**Method:** controlled fail-closed laboratory with machine-checkable proofs
**Result:** order parameters that predict capability onset across neural architectures

## Guiding statement
> BN-Syn is not a simulator of today's LLMs.
> It is a laboratory for the laws by which capabilities emerge in neural systems at all.
