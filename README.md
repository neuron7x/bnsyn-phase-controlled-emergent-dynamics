# BN-Syn — Phase-Controlled Emergent Dynamics

BN-Syn is an experimental synthetic system for exploring **phase-controlled emergence in nonlinear dynamical systems**.

The project studies how **phase parameters can regulate, stabilize, and shape emergent attractor structures** in simulations inspired by neuroscience, thermodynamics, and biological self-organization.

It also demonstrates an engineering methodology: developing research-grade repositories through **multi-LLM orchestration** with reproducibility-first governance.

## Concept

Complex biological and neural systems exhibit emergent dynamics generated by nonlinear interactions.

BN-Syn explores the hypothesis:

> Emergent attractors can be intentionally stabilized through **phase-based control mechanisms** applied to thermodynamic and dynamical parameters.

Instead of forcing deterministic trajectories, BN-Syn modulates **phase conditions** so structures emerge naturally and are then stabilized.

This framing is informed by:

- dynamical systems theory
- neuroscience-inspired computational modeling
- complex adaptive systems
- biological self-organization

---

## Project Goals

1. Evaluate whether emergent attractors can be **controlled without collapsing emergence**.
2. Test whether phase parameters can serve as **low-energy control levers**.
3. Validate whether **AI-assisted engineering pipelines** can produce reproducible research systems.

---

## Engineering Methodology (Multi-LLM Orchestration)

The repository is built with an AI-orchestrated workflow where models are used in explicit roles:

| Role | Function |
| --- | --- |
| Architect | System design and decomposition |
| Critic | Structural and scientific review |
| Refactorer | Implementation hardening |
| Tester | Validation and test design |
| Documenter | Technical and research narrative synthesis |

Representative model/tooling families used during orchestration include GPT-class models, Claude, Gemini, Grok, and Codex-style tooling.

Development is organized as **iterative critique-and-improve loops** until implementation, validation, and documentation converge.

## Repository Structure

```text
.github/              CI workflows and automation
.repo-governor/       repository governance checks

src/bnsyn/            core simulation and CLI code
src/contracts/        contracts and integration boundaries

tests/                test suites (core, validation, properties, benchmarks)
examples/             runnable usage examples
experiments/          experiment scenarios and utilities

docs/                 architecture, onboarding, proof and safety docs
specs/                formal/specification artifacts
schemas/              schema definitions

PROOF_BUNDLE/         reproducibility logs and proof artifacts
artifacts/            generated outputs and readiness bundles
results/              experiment result snapshots
figures/              generated visualizations
calibration_pack/     calibration harness and goldens
entropy/              entropy and guard analyses
benchmarks/           baseline/scenario benchmark assets
```

The layout is reproducibility-oriented: implementation, evidence, and governance artifacts are versioned together.

## System Components

### Emergence Engine
Simulates nonlinear interactions among system components.

### Phase Controller
Applies phase controls that influence stability and attractor behavior.

### Entropy Analysis
Measures structural organization and emergent complexity.

### Attractor Stabilization
Detects and stabilizes candidate emergent attractor regimes.

### Calibration Layer
Supports deterministic calibration and repeatable experiment setup.
